# Third-party code and data

The following are used by the scripts but are not part of this repository; obtain them from their original sources and respect their licences.

| Component | Source | Version used |
|---|---|---|
| PIPs++ (code, pre-trained model) | https://github.com/aharley/pips2 (Zheng et al., 2023; Harley et al., 2022) | commit 8b5bd9e |
| FlowVeloTool (PTV) | https://github.com/AnetteEltner/FlowVeloTool (Eltner et al., 2020) | commit 7f40008 |
| TAP-Vid metrics and visualisation | https://github.com/google-deepmind/tapnet (Doersch et al., 2022) | `tapvid_metrics.py`, `tapnet_viz.py` |
| TAP-Vid-DAVIS benchmark | DeepMind (Doersch et al., 2022) | not redistributed |
| Blender (fluid simulation, rendering) | https://www.blender.org | 5.2 |

Some scripts in this repository are adapted from PIPs++ scripts; the changes are listed in Appendix A.3 of the thesis.
